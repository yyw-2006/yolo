# 测试说明

本项目提供了一套完整的自动化测试脚本，用于评估模型在测试集上的表现，并生成详细的准确率报告和可视化图表。

## 1. 测试集目录结构

测试数据集存放在项目根目录的 `testdataset/` 文件夹下。该目录按照**业务违规标签**（即最终输出的类别）划分为多个子文件夹。将测试图片放入对应的文件夹中，测试脚本会自动将文件夹名称作为该图片的**真实标签（Ground Truth）**。

目录结构示例：
```text
yoloidentify-yolov8WithRule/
└── testdataset/
    ├── 暴恐/
    │   ├── image1.jpg
    │   └── image2.jpg
    ├── 违禁毒品/
    ├── 纳粹符号/
    ├── 赌博/
    ├── 不雅手势/
    ├── 游行集会/
    ├── 涉政/
    └── 正常/
```

## 2. 环境准备

在运行测试脚本之前，请确保已安装必要的评估依赖包（主要用于数据处理和图表生成）：

```bash
# 激活你的虚拟环境
# conda activate pic_recog 或 source .venv/bin/activate

# 安装依赖
pip install pandas matplotlib seaborn tqdm tabulate
```

## 3. 运行测试

进入项目的主工作目录（`yoloidentify-yolov8WithRule/`），直接运行评估脚本：

```bash
cd yoloidentify-yolov8WithRule
python scripts/evaluate.py
```

脚本运行过程中，会显示进度条（tqdm），逐张处理 `testdataset/` 下的所有图片。

## 4. 查看测试结果

测试完成后，所有的评估结果会自动保存在 `outputs/` 目录下。主要包含以下文件：

### 4.1 详细预测结果
- **`outputs/evaluation_results.csv`**
  记录了每张图片的详细测试信息，包括：图片路径、真实业务标签、预测业务标签、是否预测正确、检测到的底层类别（categories）、识别出的人脸身份等。

### 4.2 业务标签准确率（Business Label Accuracy）
- **`outputs/business_label_accuracy.csv`**：各业务标签（如“暴恐”、“涉政”等）的准确率统计表。
- **`outputs/business_label_accuracy.png`**：各业务标签准确率的柱状图可视化，方便直观分析哪些业务规则的识别率较低。

### 4.3 底层类别准确率（Original Class Accuracy）
- **`outputs/original_class_accuracy.csv`**：YOLOv8 底层 19 个类别（如 `gun`, `knife`, `blood` 等）的检出率统计。
- **`outputs/original_class_accuracy.png`**：底层类别检出率的柱状图可视化，有助于指导后续 YOLOv8 模型针对特定类别的训练优化。

## 5. 补充说明：单张图片测试

如果你只想测试单张图片并查看其详细 JSON 输出或渲染后的包围框，可以使用 `recognize.py` 脚本：

```bash
# 打印 JSON 结果到控制台
python scripts/recognize.py testdataset/暴恐/image1.jpg --enable-face

# 将结果保存为 JSON 文件
python scripts/recognize.py testdataset/暴恐/image1.jpg --enable-face --output outputs/result.json

# 保存带有检测框的渲染图片（用于可视化 Debug）
python scripts/recognize.py testdataset/暴恐/image1.jpg --enable-face --save-image outputs/annotated.jpg
```
