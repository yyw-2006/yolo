# RK3588 部署指南

本项目中的 YOLOv8 和 ArcFace 模型可以部署到瑞芯微 RK3588 平台上，以利用其内置的 NPU（神经网络处理单元）实现硬件加速。部署的核心步骤是将 PyTorch 的 `.pt` 模型转换为 RKNN 格式，并在板端使用 C++ 或 Python API 进行推理。

## 一、 环境准备

### 1. PC 端（模型转换环境）
在你的开发机（Ubuntu）上安装 RKNN-Toolkit2：
1. 下载 [rknn-toolkit2](https://github.com/airockchip/rknn-toolkit2) 仓库。
2. 创建 Python 3.8/3.10 虚拟环境。
3. 安装依赖和 rknn-toolkit2 的 wheel 包：
   ```bash
   pip install -r doc/requirements_cp310-1.6.0.txt
   pip install packages/rknn_toolkit2-1.6.0+81f21f4d-cp310-cp310-linux_x86_64.whl
   ```

### 2. RK3588 板端（运行环境）
确保板端已安装 RKNN-Toolkit-Lite2 或 C API 运行库（RKNPU2）：
1. 下载 [rknpu2](https://github.com/airockchip/rknpu2) 仓库。
2. 安装 Python 运行库（如果使用 Python 部署）：
   ```bash
   pip install rknn_toolkit_lite2-*.whl
   ```

## 二、 YOLOv8 模型转换与部署

### 1. 导出为 ONNX 格式
首先在 PC 端使用 Ultralytics 将 `yolov8n_cls_best.pt` 导出为 ONNX 格式：
```bash
pip install ultralytics
yolo export model=yoloidentify/weights/识别物品/yolov8n_cls_best.pt format=onnx opset=12
```
*注意：RKNN 官方推荐导出时移除后处理（NMS），以提升 NPU 效率。具体可参考 [rknn_model_zoo/examples/yolov8](https://github.com/airockchip/rknn_model_zoo/tree/main/examples/yolov8) 中的导出脚本。*

### 2. 转换为 RKNN 格式
编写转换脚本 `convert_yolo.py`：
```python
from rknn.api import RKNN

# 创建 RKNN 对象
rknn = RKNN(verbose=True)

# 配置模型参数 (RK3588)
rknn.config(mean_values=[[0, 0, 0]], std_values=[[255, 255, 255]], target_platform='rk3588')

# 加载 ONNX 模型
ret = rknn.load_onnx(model='./yolov8n_cls_best.onnx')

# 构建模型 (开启量化需准备 dataset.txt 包含几百张代表性图片路径)
ret = rknn.build(do_quantization=True, dataset='./dataset.txt')

# 导出 RKNN 模型
ret = rknn.export_rknn('./yolov8_rk3588.rknn')
rknn.release()
```

### 3. 板端推理
在 RK3588 上使用 Python 或 C++ API 加载 `.rknn` 模型进行推理。
参考代码：[rknn_model_zoo/examples/yolov8/python](https://github.com/airockchip/rknn_model_zoo/tree/main/examples/yolov8/python)

## 三、 ArcFace 人脸模型转换与部署

### 1. 转换为 RKNN 格式
ArcFace 模型（`arcface_retinaface_best.pt`）同样需要先转为 ONNX，再转为 RKNN。

转换配置要点：
- **输入尺寸**：通常为 `112x112`。
- **均值与标准差**：ArcFace 的标准化参数通常为 `mean=[127.5, 127.5, 127.5]`, `std=[127.5, 127.5, 127.5]`。

转换脚本示例 `convert_arcface.py`：
```python
from rknn.api import RKNN

rknn = RKNN(verbose=True)
# 注意这里的均值和方差
rknn.config(mean_values=[[127.5, 127.5, 127.5]], std_values=[[127.5, 127.5, 127.5]], target_platform='rk3588')

rknn.load_onnx(model='./arcface.onnx')
rknn.build(do_quantization=True, dataset='./face_dataset.txt')
rknn.export_rknn('./arcface_rk3588.rknn')
rknn.release()
```

### 2. 输入格式避坑指南（重要）
在 RK3588 上使用 RKNN 运行 ArcFace 时，有一个常见的输入格式陷阱：
- RKNN 模型期望的输入通常是 **`uint8` 类型的 `NHWC` 格式，取值范围 `[0, 255]`**。
- 如果你在传入数据前，手动用 Python 做了归一化（变成了 `float32` 的 `[-1, 1]`），会导致 RKNN 内部再次进行归一化，使得输入数据坍缩，最终提取的特征向量完全错误。
- **正确做法**：直接将 OpenCV 读取的图像（`BGR` 转 `RGB` 后），调整尺寸为 `112x112`，保持 `uint8` 格式直接传给 RKNN 引擎，让 NPU 硬件去完成归一化操作。

### 3. 特征比对
在板端获取到 512 维的特征向量后，使用余弦相似度（Cosine Similarity）与底库进行比对：
```python
import numpy as np

def cosine_similarity(feat1, feat2):
    return np.dot(feat1, feat2) / (np.linalg.norm(feat1) * np.linalg.norm(feat2))

# 阈值通常设为 0.45 ~ 0.55 之间
if cosine_similarity(query_feat, db_feat) > 0.5:
    print("识别为同一人")
```

## 四、 综合部署建议

对于实际的业务系统，建议采用 **C++ 多线程部署**：
1. **视频解码**：使用 RKMPP 进行硬件解码。
2. **前处理**：使用 RGA（2D图形加速引擎）进行图像缩放、裁剪和格式转换，避免 CPU 瓶颈。
3. **模型推理**：使用 RKNPU2 C API 在 NPU 上异步执行 YOLOv8 和 ArcFace。
4. **后处理**：在 CPU 上执行 NMS 和业务逻辑判定。

官方参考示例库：[airockchip/rknn_model_zoo](https://github.com/airockchip/rknn_model_zoo)
