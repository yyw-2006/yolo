# YOLO 图像识别项目流程说明

本项目旨在通过 YOLOv8 目标检测模型与 ArcFace 人脸识别模型，对输入图像进行多维度检测，并基于预设规则将检测结果映射为具体的业务违规标签。

## 整体流程图

请参考同目录下的 `yolo识别流程图.drawio` 文件查看可视化流程。

## 流程步骤详解

### 1. 图像输入与预处理
- **输入**：接收单张图像路径或图像数据（支持批量测试）。
- **参数配置**：可配置是否开启人脸识别（`--enable-face`）。

### 2. YOLOv8 目标检测
- **模型**：使用预训练的 YOLOv8 模型（如 `detector_19class.pt`）。
- **检测目标**：模型支持检测 19 类目标，包括：
  - 武器/暴力：`gun` (枪), `knife` (刀), `blood` (血迹), `police` (警察)
  - 毒品：`syringe` (注射器), `powder` (粉末)
  - 违禁符号：`swastika` (纳粹符号)
  - 赌博：`poker_card` (扑克), `dice` (骰子), `chip` (筹码), `roulette` (轮盘), `slot_machine` (老虎机)
  - 不雅手势：`middle_finger` (竖中指)
  - 集会/游行：`crowd` (人群), `flag` (旗帜), `banner` (横幅), `signboard` (标语牌)
  - 人脸：`face` (人脸)

### 3. 人脸识别与身份比对（可选）
- **触发条件**：如果在目标检测阶段检测到了 `face`，且开启了人脸识别功能。
- **人脸检测与特征提取**：使用 InsightFace（RetinaFace 提取人脸框和关键点，ArcFace 提取人脸特征向量）。
- **身份比对**：将提取到的人脸特征与本地人脸库（Facebank）进行比对（计算余弦相似度）。
- **结果输出**：返回匹配到的人名（如“某某某”），若未匹配则返回“普通人”。

### 4. 业务标签映射（Rule Layer）
根据目标检测的结果和人脸识别的结果，按照优先级规则映射到最终的业务违规标签。映射规则按以下顺序判断，一旦命中即返回：

1. **涉政**：如果人脸识别匹配到的人名存在于 `political_persons.txt`（政治人物名单）中。
2. **暴恐**：如果检测到 `gun`, `knife`, `blood`, 或 `police`。
3. **违禁毒品**：如果检测到 `syringe` 或 `powder`。
4. **纳粹符号**：如果检测到 `swastika`。
5. **赌博**：如果检测到 `poker_card`, `dice`, `chip`, `roulette`, 或 `slot_machine`。
6. **不雅手势**：如果检测到 `middle_finger`。
7. **游行集会**：如果检测到 `banner`, `flag`，或者同时检测到 `crowd` 且人脸数量 $\ge 1$。
8. **正常**：如果以上规则均未命中。

### 5. 结果输出
- **输出格式**：JSON 格式。
- **包含信息**：耗时、设备、检测到的类别列表、业务类别（`business_category`）、人脸识别结果（包含人脸数、身份信息）、以及详细的检测框坐标和置信度。
